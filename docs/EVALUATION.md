# 分割评估

准备 10–15 张覆盖照明、清晰度和粘连程度的光镜照片。由人工逐枚标注所有可见骨针，包括贴边、遮挡及破损对象，每枚使用独立实例，保存为 Studio 项目 ZIP；记录标注者、复核过程和每张图的来源。建议包含 Image016 和 Image026。真值和照片不提交到仓库。

先运行 `npm run dev`，再在另一个终端设置 `SCLERITE_EVAL_DATA` 为 ZIP 所在目录并运行 `npm run eval:seg`。结果写入忽略的 `eval-output/`，同日已有结果时拒绝覆盖。每张图分别使用项目内参数和仅关闭 `completeOnly` 的参数。需要已安装的 Chrome。

指标按实例 IoU 降序贪心一对一匹配，IoU 至少 0.5，报告 TP、FP、FN、precision、recall、F1@0.5 和匹配实例平均 IoU。预测覆盖两个以上真值各自至少 20% 算欠切；真值被两个以上预测各自覆盖至少 20% 算过切。无置信度，不计算 AP。无匹配时平均 IoU 留空。无正例的 precision、recall 和 F1 记为 0。

分别报告全部真值和排除贴边真值的范围。后一范围中，与贴边真值相交且不与非贴边真值相交的预测不计作误检；同时接触两类真值的预测保留，面积按原预测计算。范围的选择会影响指标解释。

同一样本的多张照片并非独立个体；人工真值也有误差。结果仅描述所选照片，不能直接当作跨仪器或跨物种的通用精度。基线数字：待维护者运行 `npm run eval:seg` 后填写。
